# Generated game art

The five racer portraits were generated for this project with the built-in
OpenAI image generation tool, then resized to 512×512 RGBA for the mobile Web
build. They share the `STYLE_FORMULA_V2` direction documented under `design/`.

| File | Prompt subject |
| --- | --- |
| `client/assets/art/portraits/red-corgi.png` | Friendly corgi racer bust, red scarf |
| `client/assets/art/portraits/blue-kitten.png` | Playful kitten racer bust, blue neckerchief |
| `client/assets/art/portraits/green-rabbit.png` | Cheerful rabbit racer bust, green bandana |
| `client/assets/art/portraits/yellow-duck.png` | Bright duck racer bust, yellow cap and ribbon |
| `client/assets/art/portraits/purple-fox.png` | Clever fox racer bust, purple scarf |

Shared prompt constraints: premium rounded 3D toy render; centered
head-and-upper-chest three-quarter portrait; soft warm daylight; readable at
96 px; one character; genuinely transparent background; no frame, card, text,
letters, watermark, props, or scenery.

The original generated images remain outside the project workspace. Only the
optimized runtime copies above are shipped.
